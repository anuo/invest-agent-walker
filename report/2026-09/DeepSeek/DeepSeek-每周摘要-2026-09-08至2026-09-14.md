## 一、本周概览

**一句话概括：这是 DeepSeek "模型 + 资本 + 组织"三线同时推进的一周，也是公司从"研究机构"向"公众公司"过渡的关键节点。**

- **9月8日**：启动成立以来最大规模的一次**专项扩招**——一次性放出约 **150 个工程师岗位**，全部为服务端开发与 Agent 弹性计算方向，**无一个 AI 研究岗**。
- **9月9日**：路透社报道 DeepSeek 已聘请**中信证券**筹备**上交所科创板 IPO**，目标年内递交申请、2027年挂牌；同日官宣 Flash 系列 API **降价**。
- **9月10日**：正式发布 **DeepSeek-V4.1-Flash**——552B MoE、全新 Causal Encoder-Decoder 非对称架构、原生多模态、MIT 许可开源，官方称其在性能/费用/速度/总用时上**全面超越自家旗舰 V4 Pro**。
- **9月10–11日**：一场"V4 Pro 下线又撤回"的公告风波，成为本周最受争议的信任事件。
- **9月12日**：App 灰度测试 **AI 语音对话**，补齐"语音输入→语音输出"完整链路。
- **9月14日**：媒体曝出高瓴创投合伙人**严文韬**将出任 DeepSeek **首任 CFO**（9月21日到岗），终结公司三年 CFO 空缺。

**本周的关键张力**：DeepSeek 用一款"更小、更强、更便宜"的模型，把开源阵营的成本基准线又向下压了一格；同时用一次 IPO 传闻和一次 CFO 到岗，把自己正式推上了资本市场的牌桌。但**本周没有梁文锋本人的任何公开发言**——公司层面的动作本身就是其"克制 + 开源 + 工程化"理念的执行。

## 二、实际控制人对外发言要点

**结论：区间内（9月8–14日）未检索到梁文锋本人及 DeepSeek 高管的任何直接公开发言**（采访、演讲、内部信、署名文章、社交媒体）。中英文多组关键词交叉检索确认。这与梁文锋自 2025 年初 R1 出圈以来**长期不接受媒体采访、极少公开露面**的一贯风格一致。

**区间内唯一的"管理层声音"是工程师层面**：9月7日晚（紧邻区间起点），DeepSeek Harness 团队负责人**崔添翼**发布招聘帖，称这是"**前所未有的 150 个 HC 的招聘需求**"，并解释了扩招逻辑——"计算机领域的任何东西量变大之后，就会产生复杂度上巨大的增加……数据的量、机器/容器的量、训练任务的量、评测任务的量、Agent 环境的量、用户的量、请求的量都在急剧增加，这就产生了越来越大的复杂度，会让之前的后端系统逐渐不能完美满足将来的量的需求，所以需要大量扩招人来升级、维护和重写各种后端系统。"（注：崔添翼属团队负责人，非公司高管）

为理解其当前思路，参照区间前后最近的两次实质发声：

| 日期 | 场合 | 要点 |
|---|---|---|
| 2026-07（区间前约2个月，实录7月起流传） | **4小时投资人闭门交流会实录**（超3.4万字） | ① "DeepSeek 只有一条主线，就是 **AGI**，其他都是策略/副产物"；② **"克制是一种战略"**——"你越克制，就越有可能做成这件事"；③ 开源就是让利，只赚"合理利润"（一批设备约**10个月回本**）；④ **"公司唯一的核心利益是团队稳定性"**；⑤ "我们创新缺少的不是资本，而是信心，以及组织高密度人才的能力"；⑥ 技术路线：CoT → Agent → 持续学习 → 具身智能。 |
| 2026-09-21/22（区间后约1周，The Information 转述） | 闭门投资者会议 | ① 训练转向**国产/华为昇腾芯片**是公司**最大押注之一**，且**"必须成功"**；② 判断华为芯片"几年内有望追平英伟达"；③ 正训练 **2万亿参数模型**（规划 8万亿）；④ 计划投入约 **300 亿元**国产算力。**DeepSeek 与华为均未官方置评。** |

**要点总结**：本周梁文锋处于"沉默期"，无增量观点输出。但公司的三个动作——**降价（V4.1-Flash 定价击穿自家旗舰）、开源（MIT 许可）、扩招工程岗（补齐平台能力）**——正是其"克制 + 开源 + 靠规模而非壁垒赚钱"理念的直接执行。尤其值得注意的是：**本周的降价是"主动把自家旗舰送下线"式的降价**，这与梁文锋"只赚合理利润、不追求最大化商业利益"的表述高度一致。9月下旬流出的"押注国产芯片必须成功"则揭示了这枚硬币的另一面：**成本优势的另一半是算力自主的巨额资本开支**。

## 三、企业文化观察

本周无专门的"文化事件"，但**9月8日的扩招与9月14日的 CFO 到岗**，恰好是观察 DeepSeek 文化在"规模化"压力下如何演化的两个切面。

### 本周的两个文化切面

1. **9月8日：一次"反直觉"的招聘**
   - 一次放出约 **150 个 HC**，相当于"再招半个 DeepSeek"（公司当时约 300 人，V4 技术报告列名研发者近 300 人）。
   - **岗位全部是工程岗，0 个 AI 研究岗**：服务端开发工程师（大模型研究平台、Agent 框架组件、研发效率基建、DeepSeek API、线上服务、数据工程 六个方向）+ Agent 弹性计算研发工程师（平台开发、底层系统 两个方向，面向 **DSec** 生产级沙箱平台）。
   - 用人标准从"应届生/年轻研究员"转向 **"2–10 年经验的资深工程师"**；工作地北京为主、部分杭州。
   - **解读**：这不是研究扩张，而是**"研究端精悍、工程端增兵"**——DeepSeek 正把竞争重心从"模型能力"转向"API 稳定性、推理成本、Agent 工作流、企业集成"。

2. **9月14日：三年来的第一位 CFO**
   - **严文韬**，1991年生（"90后"），复旦大学环境科学与工程系毕业；履历为腾讯投资 → H Capital → 高瓴创投合伙人，代表投资字节跳动、智谱、MiniMax、小红书、极兔等（其在高瓴期间**并未投资 DeepSeek**）。
   - 这是 DeepSeek 成立三年来的**首设 CFO 岗**。媒体称梁文锋希望 CFO 是"90后"——与其一贯的用人偏好（能力 > 资历、年轻化）一致。
   - **解读**：CFO 到位 + LP 名单严审 + IPO 冲刺三件事同时发生，标志着公司正从"梁文锋的 DeepSeek"转变为"市场的 DeepSeek"。

### 文化画像（延续并演化中）

| 维度 | 表现 |
|---|---|
| **克制式管理** | 不设严格 KPI、不打卡、不强制加班；梁文锋认为"一个人每天能高质量工作的时间很难超过 6–8 小时，加班疲劳下的昏庸判断反而会浪费宝贵的算力资源"。 |
| **极致扁平** | 弱层级、无部门墙，基础模型/底层基建/数据团队交叉分工；研究员可自由调用算力、无需层层审批（MLA 架构源于一位年轻研究员的个人兴趣提案）。 |
| **开源与合理利润** | 坚持开源（V4.1-Flash 采用 MIT 许可）；主张"十个月收回设备成本"式的合理利润，而非最大化商业利益。 |
| **用人偏好** | "能力比资历重要，好奇心比履历重要"；偏好顶尖高校应届生与年轻研究员，V2 团队无人从海外回来。 |
| **资本控制权** | 首轮融资中梁文锋个人出资约 200 亿元（最大单一出资方）；外部投资方**仅享分红权，无投票权与董事席位，股份锁定五年**；梁掌握高度控制权。 |
| **本周新增张力** | **规模化挑战**：150 人工程扩招 + CFO 到岗 + 组织翻倍，早期依赖理想主义与高度信任的文化如何延续，是梁文锋本人承认的现实挑战。 |

### 人才流动

- **区间内未检索到新的核心成员离职报道**。本区间内唯一确认的高层人才变动是**严文韬入职任 CFO**（净流入）。
- **已知的持续流失（时间范围 2025H2–2026H1，不在本区间）**：至少 5 名核心研发成员离职——郭达雅（R1 核心研究员/GRPO 主要贡献者）→ 字节 Seed；罗福莉（V2 关键开发者）→ 小米 MiMo；王炳宣（第一代 LLM 核心作者）→ 腾讯混元；魏浩然（OCR 系列核心作者）→ 百度；阮翀（多模态核心贡献者）→ 元戎启行。V4 技术报告近 300 人作者名单中，**有 10 人标注"已离职"**。
- **流失背景**：期权缺乏估值参考、薪资仅行业中游，而字节/腾讯/小米等以 2–3 倍高薪 + 期权挖角。**IPO 提供的期权退出路径，正是梁文锋推动上市的核心动机之一**（路透社 9月9日报道称，梁文锋希望 IPO 资金用于加强对核心员工与研究人员的激励）。

**文化总结**：一家"克制式管理 + 极致扁平 + 开源信仰 + 年轻本土团队"的 AI 原生公司，正处在**从"小而美的研究机构"向"工程化公众公司"的转型期**。本周的扩招与 CFO 到岗是这一转型的标志性动作；文化底色未变，但**规模化带来的传承张力正在显现**。

## 四、护城河变化评估

**总判断：本周护城河"经济性与分发端加固、技术领先性与人才端受侵蚀"，净变化为温和加固。但护城河的性质正在从"模型技术领先"迁移为"规模经济 + 生态绑定 + 资本耐力"。**

### 加固的证据

1. **成本/经济性护城河（强）**
   - V4.1-Flash **上线即降价**，缓存命中输入降至 0.02 元/百万 token（空闲时段），为行业最低档。
   - Artificial Analysis 智能指数显示 V4.1-Flash 达 **39.5**，为 DeepSeek 全系最高（超 V4 Pro 的 36.3），**单任务成本仅 $0.27**（V4 Pro 为 $0.67）——"更小尺寸超越自家旗舰"。
   - API 业务毛利率 **82.9%**（2026年前7个月，The Information 口径），在开源阵营中罕见地实现了正向单位经济。
2. **开源生态与分发护城河（强）**
   - MIT 许可 + Hugging Face 开源，发布当日 **腾讯 WorkBuddy/CodeBuddy 全量接入**。
   - **OpenRouter 数据**：2026年9月国产模型占 Token 份额 **61.9%**，其中国产内部 **DeepSeek 约 34.9%** 居首；周榜（截至9/28）**DeepSeek V4.1 Flash 以 20.8T Token 居第一**，厂商请求份额 24.4% 第一。
   - 开发者本地部署热情高涨（NVIDIA DGX Spark 论坛讨论 EXL3 量化部署；vLLM 已支持）。
3. **算力/资本护城河（强，但重资产）**
   - **乌兰察布约 1GW 数据中心**，拟部署 **≥16万颗华为昇腾 950DT**，仅芯片名义投资 **>400 亿元**（媒体报道，未经官方确认）。
   - 二轮融资投前估值约 **5000 亿元**，聘中信证券筹备科创板 IPO——资本弹药充足。
4. **品牌**：仍是中国 AI"成本革命"的符号；9月24日 The Information 报其年化收入突破 **10亿美元**，被外媒作为"中国 AI 商业化转折点"案例。

### 被侵蚀的证据

1. **技术领先性被追平/被更便宜者压制（中-强侵蚀）**
   - 摩根士丹利（9/10）：降价后 DeepSeek V4 Flash 在主流轻量模型中**仍非最便宜**——Qwen3.8-flash 输出 3 元、**GLM-5.3-flash 仅 1.4 元**。
   - **开源本身在侵蚀壁垒**：竞品可蒸馏、微调甚至商用 DeepSeek 的权重，技术代差难以长期维持。
2. **人才护城河（明确侵蚀）**
   - 2025H2–2026H1 至少 5 名核心研发离职（见第三节）；本周新增 150 人**无 AI 研究岗**，用人重心从"培养年轻研究员"转向"资深工程化"。
3. **竞争强度上升**
   - 9月11日上海 AI 实验室发布 **Atria Dawn Preview**（744B MoE）、月之暗面发布 **Kimi K2.8 Preview**；智谱 GLM-5.3 系列持续迭代——开源赛道"周更"化。
   - 智谱、MiniMax 上市后手握重金高薪挖角。

### 本周护城河变化一览

| 护城河类型 | 本周方向 | 关键依据 |
|---|---|---|
| 成本/经济性 | **加固** | V4.1-Flash 降价 + AA 指数 39.5 + 单任务成本 $0.27 |
| 开源生态/分发 | **加固** | MIT 开源 + WorkBuddy 全量接入 + OpenRouter 用量第一 |
| 算力/资本 | **加固（重资产）** | 乌兰察布 1GW/16万颗昇腾 + 5000亿估值 + IPO 筹备 |
| 技术领先性 | **中性偏侵蚀** | GLM-5.3-Flash / Qwen3.8-flash 更便宜；开源可被蒸馏 |
| 人才 | **侵蚀** | 5+ 核心研究员流失；扩招无研究岗 |

## 五、商业模式变化研究

**判断：本周商业模式无结构性变化——仍是"免费 App 换规模 + 付费 API 变现"，无 C 端订阅、无广告。但本周的动作在"变现效率"与"资本结构"两个维度上明显推进。**

### 1. 收入模式（未变）

- **主收入 = 开发者 API**：按 token 计费，预付余额，**无座席合同、无年费最低消费**；采用缓存命中/未命中差异定价 + 峰谷定价。
- **C 端 App 完全免费**：无订阅、无广告、无内购（对比 ChatGPT Plus / Gemini Advanced 约 $20/月）。这是刻意策略——**用免费分发换规模与品牌，再靠 API 变现**。
- **企业/私有化**：以 MIT 许可开源权重覆盖"本地部署/主权 AI"需求；通过集成商、云托管商触达企业；OpenAI/Anthropic 兼容 API 降低迁移摩擦。
- **用户规模**：中国月活约 **1.3 亿**（QuestMobile 2026年5–6月口径），国内 AI 原生应用**第三**，仅次于豆包（约3.82亿）、千问（约1.67亿）。

### 2. 本周的定价与变现动作

- **9月9日降价**（次日生效）：缓存命中输入 0.05→0.02 元、未命中 1.5→1 元、输出 4.5→4 元——距 8月17日刚引入峰谷定价不足一月。

6. **架构与工程能力**：V4.1-Flash 以更小尺寸超越自家旗舰，验证了"效率优先"路线的有效性。

### 6.3 DeepSeek 的竞争劣势

1. **技术差异化被侵蚀**：开源权重可被蒸馏/微调/商用；GLM-5.3-Flash、Qwen3.8-flash 在轻量档更便宜。

5. **多模态交互落后**：语音仅 TTS 级灰度，落后豆包/GPT-Live/Gemini Live；视觉读图能力在第三方实测中仍偏弱。

## 七、核心产品更新要点

> **本区间内 DeepSeek 的唯一官方核心模型更新是 9月10日的 DeepSeek-V4.1-Flash。** R2、Coder、独立多模态、V4.1-Pro 均未在本区间发布。

### 1. DeepSeek-V4.1-Flash 发布（9月10日，本周最重要）

- **定位**：全新模型结构系列中**尺寸最小的模型**，官方宣传语"更强、更快、更普惠"；具备**原生多模态视觉理解能力**。
- **架构**：**552B（5520亿）参数 MoE**，采用全新 **Causal Encoder-Decoder（因果编码器—解码器，CED）** 非对称结构——**处理输入（prefill）仅激活 8B 参数，生成输出（decode）激活 16B 参数**；对"输入密集型"Agent 场景尤为成本高效。40 层（编码器/解码器各 20 层），使用 CSA2（Compressed Sparse Attention 2）。
- **KV Cache 压缩**：结合 CSA2 跨层 KV 复用与 **FP4 KV 缓存**，全局 KV 缓存降至每 token **890 字节**，对 HBM 需求减少到 **1/4**、对 SSD 需求减少到 **1/8**（官方称相对初代模型 KV Cache 已缩小 437 倍）。
- **规格**：支持 **100万 Token（1M）上下文**、最大 **384K 输出**；支持 JSON Output、Tool Calls、Responses API、low/high/max 三档思考强度。
- **预训练**：多模态语料 **45T tokens**。
- **开源**：**MIT 许可**，权重发布于 Hugging Face（`deepseek-ai/DeepSeek-V4.1-Flash`），随模型发布技术报告 PDF；arXiv 版《DeepSeek-V4.1-Flash: Pushing the Limits of KV Cache Compression》（arXiv:2609.19969）于 **9月17日**（区间后）提交。据报道权重分 48 个分片，官方称大规模自部署需约 **2000 张 GPU + 存储集群**（第三方口径）。vLLM 已支持，NVIDIA NIM 模型卡 9月18日上线。
- **基准成绩（官方口径）**：GPQA Diamond **90.9**、Codeforces 竞赛编程 **3471**、Terminal-Bench 2.1 **90.6**（V4 Pro 为 87.9）、CyberGym 网络安全 **88.1**（V4 Pro 为 83.3）、HLE 36.8（含工具 63.9）、MathArena Apex 65.6、DeepSWE v1.1 **74.2**、NL2Repo-Bench 65.4、SEC-Bench Pro 62.8、Automation-Bench 54.8、Agents' Last Exam 31.8；多模态侧 Chartography（含工具）78.9、BabyVision（含工具）89.6。官方称仅用 **1/3 总参数、1/4 激活参数**，世界知识/推理/编码即可媲美 V4-Pro-Base。**短板**：Terminal-Bench 3.0 仅 30.0、4.0 仅 31.2、ExploitGym 15.3——在专家级/高难度 agentic 任务上仍与巨型模型有差距。

### 2. V4 Pro 下线计划"反转"事件（9月10日公告 → 9月11日撤回，本周最具争议）

## 九、本周摘要总结（价值投资视角）

**本周（2026-09-08 至 09-14）的核心叙事**：DeepSeek 用 **V4.1-Flash（更小、更强、更便宜）+ 主动降价 + 保留 V4 Pro + 语音灰度**，巩固了"成本与分发"护城河；同时以 **中信证券筹备科创板 + 二轮 740 亿美元估值 + 首任 CFO 到岗 + 150 人工程扩招**，把自己推上了资本化的快车道。**这是一周"产品、资本、组织"三线同时推进的密集动作期。**

### 积极信号

1. **成本护城河仍是行业最强**：V4.1-Flash 以 1/3 参数、1/4 激活达到旗舰水平，上线即降价，API 毛利率 82.9%——"效率优先"路线持续被验证。
2. **开发者用量领先**：OpenRouter 国产份额第一（约34.9%），周榜 Token 用量第一——生态分发能力扎实。
3. **资本化路径打开**：科创板第五套标准 + 中信证券 + 首任 CFO，融资与激励的通道正在打开，直接缓解"人才流失"这一最大风险。
4. **组织补课方向正确**：150 人扩招全部押注工程化（API 稳定性、Agent 沙箱、数据工程），说明公司意识到"模型领先不等于产品可靠"。

### 风险信号

1. **技术领先性被开源逻辑本身侵蚀**：竞品可蒸馏/微调其权重，且 GLM-5.3-Flash、Qwen3.8-flash 在轻量档更便宜——**DeepSeek 的"最便宜"标签已被部分夺走**。
2. **V4 Pro 下线风波暴露"生产级承诺"短板**：4 天迁移窗口引发开发者强烈反弹，虽已撤回，但品牌信任受损。
3. **估值已在高位**：P/ARR 约 74 倍，远超已上市的智谱（约31x）与 MiniMax（约16x），且核心财务数据均未经审计。
4. **盈利与资本开支失衡**：前 7 个月净亏 7.15 亿元，基础设施支出 110 亿元；1GW 数据中心 + 16 万颗昇腾芯片（芯片投资 >400 亿元）是**极重的资本承诺**，成败系于国产芯片的兑现节奏。
5. **地缘风险**：9月8日被美方 CISA/NSA/FBI 列入"工业规模蒸馏"指控名单，中美 AI 摩擦升级可能影响其海外生态与芯片供应。
6. **C 端变现缺位**：无订阅、无广告，收入 100% 依赖 API，抗价格战能力受限。

### 下一验证点

1. **V4.1 Pro 正式发布**及其能否在高端能力上追平国际前沿（区间内已灰度）。
2. **二轮融资能否在 10月底前如期完成**（梁文锋向投资人的时间承诺）。
3. **科创板 IPO 能否在 2026 年内递交申报**（中信证券尚在尽调，未签辅导协议）。
4. **乌兰察布 1GW 数据中心 + 昇腾 950DT 的交付节奏**（决定其成本优势与算力自主能否兑现）。
5. **API 毛利率在持续降价中能否守住**（82.9% 是护城河的核心量化指标）。
