## 二、实际控制人对外发言要点

MiniMax 创始人、CEO 闫俊杰在本摘要区间（8月1日—8月7日）内**没有检索到独立的重大公开发言或专访**。他8月份最重要的公开场合是 8月26日的中期业绩会，落在区间之外。本周他的对外"声音"主要通过两个渠道传递：

**1. H3 开源公告（8月3日，官方口径）**

MiniMax 官方发布《开放通用智能，MiniMax H3 正式开源》，延续其一贯的技术路线表述——通过 **"Minimize the Inference Cost, Maximize the Intelligence"** 实现 **"Intelligence with Everyone"**（让智能普惠化）。开源本身即是管理层最响亮的对外表态：以开放权重换取开发者生态和行业话语权。

**2. 7月10日全员信的持续影响（背景，仍在定义其对外形象）**

虽然发生在本区间之前，但本周市场对 MiniMax 的解读仍大量引用闫俊杰7月10日全员信的承诺：

- **零薪酬**：在公司实现 AGI 之前，不再从公司领取任何薪酬；
- **股份激励**：未来四年拿出个人名下相当于总股本 4% 的股份激励长期团队成员；
- **回馈开源**：拿出 1% 股份设立专项基金，持续支持开源社区。

本周 8月3日 H3 如约开放权重（H3 发布时即承诺开源），可视为对上述承诺的兑现，强化了管理层"说到做到"的信用。

**3. 高管层面（8月5日）**

战略合作签约由 MiniMax 联合创始人贠烨祎见证、副总裁严奕骏代表签署，体现管理层对"推理成本优化 + Token 服务"基础设施路线的重视。

## 三、企业文化观察

本周可观察到的企业文化特征：

1. **开源共享的工程文化**：H3 开源权重以 self-contained 形式发布（含 processor、tokenizer、text encoder、Omni Transformer、Visual/Audio VAE），并完成华为昇腾、AMD、HuggingFace、ComfyUI 等的 Day 0 适配——对社区友好度投入很大，"让开发者先用起来"导向明显。
2. **AGI 信仰驱动的长期主义**：创始人"零薪酬直到 AGI"、4% 个人股份激励团队、1% 支持开源社区，将个人利益与公司长期目标深度绑定，属于"赌注式"而非"姿态式"承诺（对比乔布斯 1 美元年薪）。
3. **成本效率至上**："Minimize the Inference Cost, Maximize the Intelligence" 的技术信条贯穿产品定价（H3 API 价格约为主流竞品的三分之一）与本周与无问芯穹的合作（推理效能共优）。
4. **兑现承诺的信用文化**：H3 发布时承诺开源、8月3日即兑现；这种"承诺—兑现"节奏在快速迭代的大模型行业里是稀缺的组织品质。

**当前企业文化概括**：以 AGI 为愿景锚点的信仰驱动型组织，对外表现为激进开源、极致性价比、说到做到。

## 四、核心产品更新要点

### MiniMax H3 开源（8月3日，本周最重要产品事件）

- **模型规格**：33B 参数通用多模态生成模型，统一理解文本/图像/视频/音频上下文；最高 **2K 分辨率、15 秒、24 FPS、32kHz 原生立体声音频**；支持 21:9、16:9、1:1、9:16 等多种画幅；稳定支持中英在内的 **11 种语言**。
- **开源检查点**：
  - `H3-Base-FL2VA`：文生视频、首/尾帧/首尾帧生视频；
  - `H3-Base-Ref2VA`：全模态参考模式（最多 9 图 + 3 视频 + 3 音频，合计 12 个参考文件）。
- **部署生态**：HuggingFace、魔搭 ModelScope、MiniMax Hub 三渠道可下载；支持 SGLang、vLLM、diffusers、ComfyUI 部署，可多 GPU 并行本地推理（本地生成目前面向 768P，2K 仍依赖官方 API）。
- **许可证**：MiniMax H3 Community License Agreement（商用需注意条款）。
- **榜单表现**：在 Artificial Analysis 视频模型榜单中，视频编辑能力排名**全球第一**。

### 产品线背景（截至本周）

- 语言模型：MiniMax-M3（原生多模态、1M 上下文）；语音：Speech-2.8-HD / Turbo。
- H3 API：768p 约 $0.08/秒、2K 约 $0.13/秒，价格约为主流竞品的三分之一，延续"性价比"定位。

## 五、护城河变化评估

**结论：本周护城河整体在加固，但质量维度的竞争压力同时加大。**

### 加固因素

1. **开源生态先发优势**：H3 是该规模上首批开放权重的视频生成模型，社区生态一旦建立（下载、衍生模型、工作流工具链）将形成显著的转换成本。后续数据可验证：开源三周多下载量超 2400 万次、衍生模型超 300 个（截至8月底，区间外验证数据）。
2. **基础设施协同**：与无问芯穹的战略合作（8月5日）将"模型—推理—落地"链条上下游绑定，直接服务于其核心信条"降低推理成本"，有助于在价格战中维持毛利。
3. **资本通道打开**：纳入港股通（8月6日）引入南向资金，为持续的算力资本开支提供融资弹性；关联公司注册资本增至 55 亿元亦指向基础设施投入加码。
4. **国产算力适配**：昇腾 Day 0 适配 +（后续披露的）大规模国产算力集群计划，降低对海外芯片的依赖风险。

### 被侵蚀/承压因素

1. **质量标杆被字节抢占**：Seedance 2.5（7月31日发布）单次原生生成 30 秒视频、参考素材一次 50 个、时间戳级编辑，质量维度公认领先；行业形成"Seedance 2.5 成片质量 vs H3 性价比与开源"的双雄分层格局。
2. **价格战风险**：H3 的低价与开源策略可能引发全行业跟进降价，视频生成 API 的单位经济面临压缩。
3. **巨头持续加码**：快手可灵 3.0（4K/60FPS）、Google Veo 3.1、FLUX 3 Video（8月4日 GA）均在缩短与第一梯队的差距；OpenAI Sora 2 已停服退场，说明赛道淘汰赛残酷、先发优势并不牢固。

### 估值判断：**依然偏贵，属于"极高增长消化极高估值"的定价**

- 以本周市值约 1038—1100 亿港元（约 133—141 亿美元）计，对照当时市场可知的 ARR（2026年4月约 4.3 亿美元，管理层指引年底至少 10 亿美元），**PS（市值/ARR）约在 10—30 倍区间**，远高于传统软件公司 5—10 倍的水平。
- 亏损仍在扩大：上半年经调整净亏损 2.93 亿美元（同比扩大 111%），研发开支 2.97 亿美元（+138.8%）——盈利遥遥无期，估值高度依赖增长兑现。
- 卖方分歧极大：主流券商目标价区间 **500—1317 港元**（对应当前价±很大带宽），高盛将中国 AI 大模型 2026 年 ARR 预期由 100 亿美元上调至 130 亿美元，并对 MiniMax 2026—2028 收入预期上调 22%—64%。
- **价值投资者视角**：本周约 297—350 港元的价格，较 3 月高点回撤约 75%，但按经典估值框架（盈利、现金流）仍无法给出支撑；买入逻辑本质是"Token 消耗量指数增长 + B 端收入结构改善"的成长叙事。若 8 月末披露的 ARR 超 8 亿美元及 B 端占 80% 的趋势延续，估值消化速度快于预期；反之若 Token 增长放缓或价格战恶化，下行空间依然可观。**总体评价：估值偏高（成长股框架下的"合理偏贵"），不适合要求安全边际的传统价值仓位。**

## 七、商业模式变化研究

**结论：本周没有商业模式的方向性转变，但"卖 Token"模式的三大支柱本周全部得到强化。**

MiniMax 的商业模式在过去一年已完成从"C 端应用（Talkie、海螺 AI）为主"到"B 端 API/Token 为主"的换挡（后续披露：上半年 B 端收入占比 63.4%，ARR 中 To B 占 80%）。本周的三个事件均是对该模式的加固而非改变：

1. **H3 开源 → 获客漏斗**：开放权重本质是"开源获客、API 变现"的经典打法（参照 Red Hat / Meta Llama 路径），开发者本地跑 768P、商用升级 2K API，形成自然的付费转化。
2. **无问芯穹合作 → 成本端**：推理效能共优与 Token 服务共建，直接优化"单位 Token 毛利"，这是 Token 销售模式的生命线。
3. **港股通 + 增资 → 资本端**：为算力基础设施（模型即商业模式的固定成本）提供资金支持。

需要留意的模式性风险：Token 单价长期通缩是行业共识，MiniMax 的对冲手段是"规模 × 成本协同优化"（管理层后续在业绩会表述"降价与提升毛利率并非矛盾"）。

## 八、行业竞争格局

### 视频生成赛道（本周主战场）

| 玩家 | 最新动作 | 定位 |
|------|----------|------|
| **MiniMax H3** | 8月3日开源权重 | 性价比之王（约$0.08—0.13/秒，竞品的1/3）+ 开源生态 |
| 字节 Seedance 2.5 | 7月31日发布 | 成片质量之王（30秒单次生成、50个参考素材），但贵 |
| 快手可灵 3.0 | 已商用 | 4K/60FPS、原生音频，Sora 2 停服后的热门替代 |
| Google Veo 3.1 | 商用中 | 电影级画面+同步音频，$0.05—0.40/秒 |
| FLUX 3 Video | 8月4日 GA | 20秒长视频、原生音频、多语言对白 |
| OpenAI Sora 2 | 已停服（4月26日关闭App，API 宽限期至9月24日） | 教训：先发优势不牢靠 |

格局判断：**"质量（Seedance 2.5）vs 性价比/开源（H3）"双雄分层**，竞争焦点已从"能不能生成"转向价格、专项能力（编辑、一致性、时长）与 API 稳定性。

### 大模型公司整体格局

- 豆包（字节）：国民级 C 端入口 + 流量生态；
- Kimi（月之暗面）：长文本 + 知识工作 Agent；
- 智谱：政企信创、国产化部署；
- 通义千问：开源基座 + 阿里云 MaaS；
- DeepSeek：通用底座 + 极致性价比；
- **MiniMax：普惠视频创作 + 全球化 B 端多模态 API（海外收入占比约 60%）**。

### MiniMax 的竞争优势

1. 视频模型开源先发与生态位（编辑能力全球第一 + 开发者社区）；
2. 极致性价比带来的 B 端 API 份额（Token 消耗 7 月达 1 月的 20 倍）；
3. 全球化收入结构（海外约 60%），对单一市场政策风险免疫较强；
4. 上下游联盟（无问芯穹）+ 国产算力适配的 infra 能力。

### 竞争劣势

1. 绝对质量落后于字节 Seedance 2.5，"精品 vs 量产"中居于量产一侧；
2. 算力资本开支巨大、经调整亏损仍在扩大，对融资环境依赖高；
3. C 端（Talkie、海螺）面临巨头流量挤压，非主增长引擎；
4. 视频 API 赛道价格战若全面爆发，性价比优势可能被稀释。

## 九、本周摘要总结（价值投资视角）

**一句话**：产品（H3 开源）与资本（入通暴涨）双击的一周，护城河在生态与成本端加固，但估值已重新回到"需要极高增长来消化"的区间。

**看多者会说**：开源建立的视频模型生态壁垒 + Token 消耗量指数级增长 + B 端收入结构改善 + 管理层 AGI 绑定的强激励，是本轮中国 AI 中确定性叙事最完整的标的之一。

**看空者会说**：1000+ 亿港元市值对应不足 5 亿美元 ARR、经调整亏损翻倍、字节在质量维度压制、视频生成单价长期通缩——这是一只"叙事先行、盈利无期"的高波动成长股，而非价值投资标的。

**关键跟踪信号**（供后续周报沿用）：① H3 衍生生态数据（下载量、衍生模型数）；② Seedance 2.5 API 开放后的定价与份额变化；③ 南向资金净流向；④ 中期业绩会披露的 Token 消耗与 ARR 趋势（8月26日，区间外，下周摘要覆盖）。
