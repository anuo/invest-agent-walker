## 一、本周概览

本周是智谱 **"模型发布后的预期兑现周"**：GLM-5.3 在8月14日（窗口前一天）发布，但市场对"迭代而非更大参数旗舰"并不买单，叠加行业供给过剩，智谱股价一周走出 **"连续暴跌 → 触底反弹"** 的深V行情，而公司创始人、首席科学家、实际控制人之一唐杰在8月19日（周三）发长文公开回应 Scaling Law，成为本周最重要的基本面信号。

- **8月14日（窗口前一天）**：发布 **GLM-5.3**——与 GLM-5.2 同基座（约7530亿总参数、400亿激活参数），能力提升全部来自"一个月的后训练（长时域环境训练+强化学习）"，宣称"开源编程能力第一"、网安能力持平 Mythos 5，AA 指数由53分升至60分。
- **8月17日（一）**：股价收 1203 港元，**-5.28%**；主力资金净流入2.87亿港元（承接与抛压并存）。
- **8月18日（二）**：港股"大模型双雄"重挫，智谱 **-13.30%** 收 1043 港元、盘中最低触 990 港元；卖空股数于8/14创7/9以来新高，解禁潮+定价劣势+迭代不及预期三重压制。
- **8月19日（三）**：**唐杰在 X 发长文谈 Scaling Law，直言"万亿参数这一轮是整个领域一起走了一段弯路，然后又一起折返"**；同日 GLM-5.3 API 正式上线，股价 -2.97% 收 1012 港元、盘中最低 983 港元。
- **8月20日（四）**：微涨 +1.09% 收 1023 港元，抛压暂时止住。
- **8月21日（五）**：**+10.36%** 收 1129 港元、盘中最高 1149 港元，收复周内大部分跌幅；36氪刊发深度复盘《两个月蒸发8000亿市值，智谱唐杰坦言"走了弯路"》。

一周股价（周一 1203 → 周二低点 990 → 周五 1129），较6月峰值约2980港元回撤超60%；截至窗口末，总市值约 **4720–5250 亿港元（约600–670亿美元）**。

## 二、实际控制人发言要点

**智谱的实际控制人为唐杰（联合创始人、首席科学家、清华教授）、刘德兵（董事长）二人**，通过一致行动人（含李涓子、许斌、张鹏、宁波慧惠等）合计控制约 **36.96%** 表决权（唐杰直接持股约7.41%；刘德兵直接持股约0.26%并通过持股平台控制约17.40%表决权）。CEO 张鹏为一致行动人之一，非实际控制人。

**摘要区间内，唐杰 8月19日 X 平台长文是唯一的实际控制人直接公开发声**，其余高管（刘德兵、张鹏）窗口内无直接公开输出。要点整理：

### 唐杰 8月19日长文（谈 Scaling Law 与 GLM-5.3）

核心论点：
1. **"万亿参数是行业走过的弯路"**："万亿参数这一轮，回头来看，是整个领域一起走了一段弯路，然后又一起折返。"回顾 Scaling Law 两阶段：2020年 Kaplan 提出参数增速应快于数据（约2.7:1），催生 GPT-3/Gopher/MT-NLG 等超大规模模型；2022年 Hoffmann（Chinchilla）发现算力该按"每参数约20个Token"配置，参数与数据应大致同步增长。早期拟合误差随算力量级放大，导致当时最大的模型恰恰是算力分配最失衡的。
2. **参数量不是唯一维度**：讨论模型规模必须同时看训练数据规模、算力投入位置、以及"由谁、在什么条件下运行"。
3. **推理成本与 MoE 使最优解持续移动**：模型如今每天被调用数十亿次，推理成本远超一次性训练成本，最优解向"更小模型、训练更久"移动；MoE 下应分开看——总参数决定知识存储、激活参数与有效计算深度决定长程推理能力。
4. **GLM-5.3 是一次"控制变量实验"**：与 GLM-5.2 共用同基座、同架构、753B 总参 / 40B 激活，唯一变量是"一个月长时域环境训练+强化学习"的后训练，AA 指数从53→60（+7分），"提升并非微小"。

**要点总结**：唐杰的窗口内发言本质是**一场"预期管理"与"路线辩护"**——在股价因"迭代不及预期、只会后训练"质疑而单周重挫之际，主动把"不堆参数"从被动质疑转为主动方法论，明确公司技术与估值重心的切换信号（从"规模崇拜"转向"后训练/深度扩展"）。

### 前后最近的辅助发声（用于理解其当下思路，均已标注时点）

| 日期 | 场合 | 要点 |
|---|---|---|

## 三、企业文化

窗口内无专门的"文化事件"，但8月的动作与发言延续并强化了公司一贯文化画像：

1. **AGI 信仰为锚的长期主义**：使命"让机器像人一样思考"，2019年创立以来未动摇；唐杰强调"别人敲钟，我们归零"——2026年1月H股上市当天即要求团队把上市当全新起点、全面回归基础模型研究，而非短期变现。
2. **本质、反直觉、专注**：唐杰出圈的十二字方法论——"想得足够深，才敢选得足够反；选得足够反，就必须守得足够久"。本周"不堆参数、只炼后训练"的 GLM-5.3 正是这一"反直觉"路线的落地。
3. **至真至纯的理想主义 + 科研基因**：清华系血统（唐杰/李涓子均为清华教授），对外口径长期强调"押注最烧钱的 AGI 孤径"，Touch High 计划"不登顶就是失败"体现极致的科研执念。
4. **All-in-Infra 的工程信仰**：以国产芯片作为主力推理算力、单位 Token 推理成本8个月内下降80%，把"极致降本"内化为组织能力而非口号。

**总结**：一家"清华底色的 AGI 信仰组织"——以长期主义与科研理想主义为内核，方法论偏"本质、反直觉、专注"；本周"拒绝追逐万亿参数、公开承认弯路"的姿态，是这一文化面对资本压力时的一次集中外化。代价是：与市场短期预期的错配，以及高昂研发投入（H1研发开支21.31亿元）带来的持续亏损。

## 四、核心产品更新要点

### 1. GLM-5.3 发布（8月14日发布，窗口前一天；本周进入发酵与上线）
- **技术定位**：与 GLM-5.2 同基座（约7530亿总参数 / 400亿激活参数、支持1M上下文、最大131K输出），**架构与参数完全不变**，全部能力跃升来自"极致后训练"——一个月长时域环境训练 + 强化学习。
- **编程能力**：内部 Z.ai Code Bench 较 GLM-5.2 提升 **50%**；Terminal Bench 3.0 等公开基准取得**开源模型 SOTA**（"开源编程能力第一"）。
- **网络安全能力（新技能树）**：白盒代码审查与漏洞发现能力持平 Mythos 5，联合中国安全团队测试累计发现 **2436 个漏洞（其中1097个中高危）**。
- **推理**：支持 low / high / max 三级思考强度（reasoning_effort）。
- **开放节奏**：权重计划在发布两周后（约8月28日）经安全评估后于 Hugging Face 开源。
- **8月19日**：GLM-5.3 API 正式上线（窗口内）。

### 2. 关联生态（本周发酵中）
- **GLM Coding Plan** 全量上线、订阅额度已重置（发布当日8/14）、Coding Plan 调用量较年初增长超23倍——订阅成为 API 之外的第二增长引擎。

### 3. 窗口内无更新的产品线
- 未发布更大参数的旗舰（市场此前期待的"更大参数模型"落空，是本周股价重挫的主因之一）。
- GLM-5.3-Flash（原生多模态、320B总参/18B激活、"牛来Ox"）为 **8月26日（窗口后）** 发布，不在本期范围。

## 五、护城河变化

**判断：护城河呈"结构性加固、叙事层面承压"的矛盾格局——工程/技术/商业化效率的护城河在加深，但"参数规模领先 + 稀缺性溢价"的旧叙事护城河正在被行业供给过剩瓦解。**

### 加固的证据
- **持续领先的迭代能力本身成为护城河**：唐杰明确提出"对 SOTA 的理解不是'领先多久'，而是'持续领先的能力有多强'"；过去11个月 GLM 家族从4.6连续迭代到5.3，能力曲线持续上行、单位任务成本保持健康。
- **后训练成为可复用的"深度扩展"壁垒**：GLM-5.3 证明"同基座纯后训练也能涨50%编程能力"，验证了后训练是"当前余量最大"的路径；智谱开源 slime 等项目，使 RL 后训练从"闭源秘籍"走向"开源基建"，卡住方法论身位。
- **国产算力 All-in-Infra 的自主可控**：10万张级国产芯片规模化低成本推理、单位 Token 推理成本8个月内下降80%，在实体清单（2025.1起被美列入）背景下形成"制裁免疫"的差异化优势。
- **商业化飞轮转正**：MaaS 平台用户740万+（+144%）、付费DAU +603%、Token调用量+40倍；开放平台/API收入8.25亿元（+2735.7%、占总收入86.5%），API毛利率从-0.4%转正至24.6%；7月ARR破10亿美元（国内本土大模型首家）。

### 被侵蚀的证据
- **"参数/技术唯一领先"叙事被 Kimi K3 打破**：7月16日月之暗面2.8万亿参数开源模型 Kimi K3 登顶 Code Arena，智谱失去"第一"的稀缺叙事，此后估值锚从"技术领先"被迫切换到"商业化兑现"。
- **定价劣势**：GLM-5.2 混合 API 价格较 DeepSeek V4 Pro 非高峰价仍高约2.2倍，面临激烈的性价比竞争；8/18起 DeepSeek 开启峰谷定价，价格战升级。
- **"只会后训练、基座不更新"的市场质疑**：本周重挫的导火索之一即是"GLM-5.2 迭代版而非更大旗舰"，市场短暂失掉对基座进展的信任（智谱后于8月底回应"下一代基座已在推进、GLM-6瞄准自进化"）。
- **资本层面的稀缺溢价瓦解**：7月解禁潮 + 卖空激增（8/14卖空88.52万股、成交11.60亿港元，创7/9以来新高）。

## 七、商业模式变化

**判断：无根本性质变，但"深度扩展降本→调用放大→毛利转正"的价值链正循环在本周得到加速验证，商业模式的"换挡"进一步深化。**

- **主线延续**：管理层将演进路径概括为"卖模型 → 卖调用 → 卖订阅 → 卖端到端任务结果"，当前重心位于 API（卖调用）+ Coding Plan 订阅（卖订阅）之间。窗口内 GLM-5.3 API 上线即是对"卖调用"的扩容。
- **收入结构已彻底换挡**（反映窗口期状态，8/31中报披露）：开放平台及API收入 8.25亿元（+2735.7%、占总收入86.5%，去年同期仅15.2%），本地化部署收入占比从84.8%降至13.5%——一年间由"一次性项目交付"转为"持续性云服务"。
- **"反常识"的量价齐升正循环**：Token调用量+40倍的同时，API 平均售价+101%、单位 Token 推理成本-80%、MaaS 毛利率从-0.4%转正至24.6%；逻辑是"模型能力越强，用户买的不再是模型，而是模型替自己完成工作的能力"，定价从"每百万Token多少钱"走向"完成一个任务多少钱"。
- **订阅第二引擎成型**：GLM Coding Plan 调用量较年初增长超23倍，并已全量上线（8/14），成为 API 之外的持续现金流来源（天猫渠道上架为9月初窗口后动作）。
- **未变化的隐忧**：整体毛利率因低毛利API占比提升而被摊薄（搜索数据口径下整体毛利率约26.4%，低于此前50%）；亏损虽收窄但仍处高位，商业模式能否在规模之上兑现净利润仍是未解命题。

## 八、行业竞争格局与优劣势

### 竞争格局：行业进入"供给过剩 + 周更 + 资本抢跑"阶段

1. **模型"周更"、稀缺性溢价消失**：7月 Kimi K3、8/14 智谱 GLM-5.3 与阿里 Qwen3.8、8/18 起 DeepSeek V4 Pro 调价、8/28 腾讯混元 Hy4 等密集发布，叠加 Grok 4.6——资本市场用脚投票，"大模型双雄"8/18 单日重挫逾13%。
2. **融资/IPO 军备竞赛白热化**：Kimi 500亿美元投前 Pre-IPO 并秘密递表港交所、DeepSeek 估值破500亿美元、可灵独立融资180亿美元、Anthropic 递表美股——智谱作为"先发上市者"面临可投标的扩容带来的资金分流。
3. **三大阵营竞争**：互联网巨头（百度/阿里/腾讯/字节，收拢C端入口与算力）、AI独角兽（DeepSeek/智谱/月之暗面/MiniMax/阶跃）、垂直专精者，正从"参数竞赛"全面转向"效率竞赛 + 场景落地"。

### 智谱的竞争优势
- **开源编程能力第一 + 方法论领先**：GLM-5.3 开源编程 SOTA，"后训练深度扩展"路线先下一城，slime 开源卡住 RL 后训练基建身位。
- **国产算力自主可控**：All-in-Infra、10万张国产卡、单位推理成本8个月↓80%，在美实体清单下形成"制裁免疫"差异化。
- **商业化兑现速度第一**：ARR 达16亿美元（月年化）、MaaS 用户740万+、API 毛利率转正，是国内本土大模型厂商中商业化飞轮转得最快的。
- **上市融资通道 + 网安先发**：港股上市+A股科创板在途（拟募150亿），叠加网安这一进展最快的 Co-work 场景卡位。

### 智谱的竞争劣势
- **绝对参数规模非最大**：被 Kimi K3（2.8万亿）在"规模/登顶"叙事上压制，市场对其"不再堆大"存有争议（"只会后训练"质疑）。
- **API 定价偏高**：GLM-5.2 较 DeepSeek V4 Pro 高约2.2倍，性价比竞争承压。
- **巨额亏损与高估值**：H1 净亏损20.72亿元、研发21.31亿元，P/ARR 显著高于 MiniMax，"贵"在同行中突出。
- **终端入口缺失**：无字节豆包/阿里千问级别的C端超级入口，收入高度依赖 API/B端，对"独立供应商在巨头整合下的价值捕获"存疑（摩根大通此前对 MiniMax 的同类担忧同样适用于智谱）。

## 九、价值投资者视角总结

**本周（2026-08-15 至 08-21）的核心叙事**：智谱在"新模型发布不涨反跌、市值两个月蒸发数千亿"的极端压力下，由实控人唐杰主动站出来，把"不追参数量、专注后训练"的路线之争从技术争论升级为公开方法论宣言——这是一场**估值锚切换的关键战役**：市场正在逼迫大模型公司从"谁能发布更大参数的震撼新闻"转向"谁能更快兑现收入、毛利与成本效率"。

**积极信号**：
1. 后训练"深度扩展"路径被 GLM-5.3 用数据验证（同基座编程+50%、AA指数53→60），且方法论可复用、可开源，形成非参数类壁垒；
2. "量价齐升 + 成本骤降"的反常识正循环（调用量+40x、均价+101%、成本-80%、毛利率转正）是护城河加固的最硬证据；
3. 国产算力自主可控在实体清单环境下构成稀缺的结构性优势；
4. 股价较峰值回撤60%后，估值风险已部分释放，8/21 +10.36% 的反弹显示部分资金开始按"商业化兑现"重新定价。

**风险信号**：
1. 行业"周更"竞争令稀缺性溢价逻辑彻底失效，估值锚切换带来持续高波动与下修压力；
2. "仅靠后训练、基座暂缓"若被证伪为"技术上限透支"，当前"高效迭代"叙事将反转（需 GLM-6"自进化"来兑现）；
3. API 定价劣势与 DeepSeek 价格战叠加，毛利改善的持续性存疑；
4. 巨额研发投入与负盈利，使得"贵"仍是核心约束——内在价值能否撑起35–42x P/ARR，完全取决于 ARR 能否持续高增并最终转化为净利润。

**下一验证点**：① GLM-5.3 权重约8/28开源后的生态扩散与下载量；② 8/31中报后的 ARR 是否延续月环比高增；③ GLM-6"自进化"基座（下一代"更大有效规模+原生多模态+管控激活参数"）的发布时间与能力跃迁幅度，能否回应"只会后训练"质疑；④ 年底 ARR 目标与整体毛利率的走势。
