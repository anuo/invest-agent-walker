## 一、实际控制人发言要点（唐杰、刘德兵）

智谱的实际控制人为清华系创始人**唐杰**（首席科学家、清华计算机系教授，直接持股约 7.41%）与**刘德兵**（董事长，通过一致行动人及持股平台合计控制约 36.96% 表决权）二人；CEO/总经理**张鹏**是产品与商业化的公开代言人，但不属于证监会口径的实控人。区间内实控人的发声高度集中于 **8月31日晚的中期业绩电话会**（源自 [新浪财经·第一财经](http://m.toutiao.com/group/7683770833076109875/)、[东方财富·财富号](https://caifuhao.eastmoney.com/news/20260831220628518181440)、[每日经济新闻](http://m.toutiao.com/group/7680434762607002131/)）。

**1. 刘德兵（董事长/实控人）："能力兑现"与"任务级定价权"**
- 年度关键词切换："如果去年智谱的关键词是**智能上界**，今年上半年的关键词就是**能力兑现**。"
- 对竞争本质的判断："单点榜单领先很快会被追平，真正重要的是谁能持续**用更低成本交付更高智能**，并把这条边界不断向外推移。"
- 最受关注的"定价权"表态（[东方财富·财富号, 2026-09-03](https://caifuhao.eastmoney.com/news/20260903105215636322790)）："未来行业会出现**两条价格曲线**：同等智能的价格持续下降，但能打开新任务边界、显著提升任务成功率的模型仍有定价空间。**拥有定价权的不是 token 本身，而是 token 最终能完成什么任务。**"
- 将模型能力演进划分为五阶段：Chat（对话）→ Coding（编程）→ Agent（智能体）→ Co-work（协同工作）→ **Autonomous AI（自进化人工智能）**；从 Coding 迈向 Agent 的核心是长程规划与错误恢复能力，进到 Co-work 则要求模型输出达到"可供专业人员复核"的标准。

**2. 唐杰（首席科学家/实控人）：回应"只会后训练/参数克制"质疑**
- 针对市场"智谱过度依赖后训练、是否已停止基座模型预训练"的质疑，回应称这是结合现有数据（国内训练数据约 30 万亿~50 万亿 token）与算力资源、权衡各训练阶段**边际收益后的主动选择**，而非停止迭代；下一代基座模型已在推进。
- 将模型扩展比作"调节多个旋钮"，本次选择加大后训练，但后续仍可能扩大中期训练、预训练等环节。
- 首次披露下一代模型方向为 **"Full Self-Training"（全自主训练 / 自进化）**：模型从预训练到后训练全程自主进行，并能**自我纠错、自我停止**——对标 GLM-6.0。

**3. 张鹏（CEO，非实控人，作为产品代言人补充）**：8月26日 GLM-5.3-Flash 发布时称，"核心突破不是参数规模的提升，而是**效率革命**——通过架构创新，把原本需要 1000 张 A100 的任务用 200 张国产芯片就能完成，让顶级 AI 技术走向普惠"（[新浪财经, 2026-08-26](https://cj.sina.com.cn/articles/view/7880068204/1d5b04c6c06801gjg6)）。

## 四、护城河变化：算力/成本护城河加固，模型前沿相对承压

**总体判断：分化格局——"国产算力成本护城河"显著加固，"模型性能前沿"相对位置承压，商业模型结构性改善。**

### 加固因素
1. **国产芯片成本护城河（智谱最独特的壁垒）**：实现 **10 万卡级国产芯片规模化低成本推理**，单位 Token 推理成本较年初下降 **80%**；"算力乘数"（每投一元算力对应的 API 收入）较去年上半年提升 **14 倍**；全用国产芯片承载 62 万亿 token 流量，SemiAnalysis 评论"CUDA 护城河再度受到考验"（[搜狐, 2026-08-27](https://m.sohu.com/a/1068392929_120231872/)）。这构筑了相对依赖英伟达算力的竞对的成本与供应链壁垒。
2. **量价齐升验证真实定价权**：一季度起 API 平均定价累计提升 83%（上半年累计约 +101%），调用量却逆势增长 **40 倍**——"提价不降量"，与 MiniMax"降价换量"形成对照，是护城河强弱的直接证据。
3. **开发者/开源生态网络效应**：GLM-5.3 系列开源带动 OpenRouter/OpenCode 流量登顶、vLLM/SGLang/Transformers 主流框架全适配；Flash 保留 MIT 扩大生态，旗舰换自定义许可以防御大厂"白嫖"头部能力。
4. **任务级能力壁垒**：在编码、网络安全、长程任务等"能打开新任务边界"的高价值赛道，GLM-5.3 取得 CyberGym 84.5% 的领先成绩，契合"任务级定价权"逻辑。

### 受侵蚀/承压因素
1. **模型前沿位置被 Kimi K3 反超**：区间内市场普遍认为"智谱作为原本领先的中国模型，性能已不及 Kimi K3（2.8T 参数开源、编程榜登顶）"——智谱 8/26 大幅降价（Flash 约 1/40 成本）被媒体解读为"狙击 Kimi K3"的守势动作（[新浪财经, 2026-08-27](https://cj.sina.com.cn/articles/view/9171525735/222aa606700103f1ac)）。
2. **"只会后训练、参数克制"的信任损耗**：市场质疑其是否放缓预训练、靠后训练吃老本，唐杰需公开回应（见第一节）。
3. **毛利率大幅下滑（50.0%→26.4%）**：收入结构向低毛利 API 切换的阵痛，叠加经调整净亏损扩大 12.1%，盈利路径仍高度依赖规模效应兑现。
4. **客户高度集中风险**：740 万注册用户中，仅 **189 个高质量企业客户贡献约 7 亿美元 ARR**——高度头部化意味着少数大客户流失即伤及增长。
5. **开源"开放度"边际收紧**：旗舰改自定义许可（100 亿美元营收门槛 + 商用审查），在护城河防御与开源生态吸引力之间做权衡，长期对社区友好度有潜在影响。

## 六、商业模式变化：结构性换轨已确认

**8月31日中报确认了从"本地化部署卖模型"向"云端 MaaS 卖调用"的彻底换轨**，并给出清晰的四步演进路线：**"卖模型 → 卖调用 → 卖订阅 → 卖端到端任务结果"**。

| 维度 | 2025 H1 | 2026 H1 |
|---|---|---|
| 总收入 | 1.91 亿元 | **9.54 亿元（+399.7%）** |
| 开放平台/API 收入 | 0.29 亿（占 15.2%） | **8.25 亿元（+2735.7%，占 86.5%）** |
| 本地化部署收入 | 1.62 亿（占 84.8%） | 1.29 亿元（-20.5%，占 13.5%） |
| API 业务毛利率 | -0.4% | 24.6%（由负转正） |
| 综合毛利率 | 50.0% | 26.4% |
| ARR（8 月底，按月口径） | — | 16 亿美元（较 7 月上旬 10 亿美元 +60%；按最近一周×52 更超 20 亿美元） |

要点：
- **"卖水"生意经成型**：收入引擎从"项目制交付"彻底反转为"按 token 调用的 MaaS 订阅"，API 占比一年从 15.2% → 86.5%（[华夏时报](http://m.toutiao.com/group/7680552665977340468/)、[南方都市报](http://m.toutiao.com/group/7680518565920784930/)）。
- **All-in-Infra / 国产芯片**：管理层明确算力来源多元化（自有集群 + 租赁 + 采购，以租赁为主）；董秘肖磊判断行业主要矛盾已从"国产芯片能不能跑"转向"**如何验证国产芯片的经济性**"，并强调"有效算力"（已安装、能稳定调度、转换成有效 token），而非简单堆卡。
- **从"卖 token"上移到"卖任务结果"**：定价权逻辑的核心人设——收入增长**不是"以价换量"**（API 均价反升约 101%），这是商业模式质量优于同业的关键点。
- **盈利结构痛点**：综合毛利率被高增长的 API 板块稀释（50%→26.4%），经调整净亏损仍扩大，商业模式换轨的"收入质量红利"尚未传导到利润端。

## 七、行业竞争格局与公司优劣势

**2026 年 8 月下旬的大模型格局**：中国模型进入"八周五连发"的多极混战（GLM-5.2、Kimi K3、DeepSeek V4-Flash、字节 Seedance 2.5、阿里 Qwen3.8-Max 密集发布），硅谷企业因成本"换底座"到中国开放权重模型，全球调用量前五清一色中国模型；DeepSeek 8 月提价（V4-Pro 高峰价 +350%）、智谱反向降价，体现"均值回归"与定价分化。

**主要玩家位置**：Kimi/月之暗面（K3，2.8T 参数开源、编程榜领先，正洽微软/亚马逊/谷歌返点托管）、DeepSeek（V4，性价比路线、8 月涨价）、字节（Seed/豆包，国产综合第一）、阿里（Qwen3.8-Max）、MiniMax（H3 视频第一梯队，"向下要量"）；国际侧 Claude Fable 5 / Opus 4.8、GPT-5.6、Gemini。21 世纪经济报道将"港股双雄"（智谱、MiniMax）中报对比概括为"**一个向上要价（智谱）、一个向下要量（MiniMax）**"。

**智谱竞争优势**：
1. **国产芯片算力成本护城河**：10 万卡国产芯片、推理成本 -80%、算力乘数 +14 倍，是"成本领先"型的结构性优势，且具供应链自主叙事价值。
