# 智谱 每周摘要（2026-08-08 至 2026-08-14）

> 研究公司：智谱（北京智谱华章科技股份有限公司 / Zhipu AI / Z.ai，港股 02513.HK，「全球大模型第一股」）
> 摘要区间：2026-08-08 至 2026-08-14（8/8、8/9 为周末，实际交易日为 8/10–8/14）
> 报告生成日期：2026-09-10

---

## 本周概要

本周是智谱「预期抢跑 → 利好兑现即回落」的一周，全部焦点落在 **8/14 GLM-5.3 发布** 这一件事上：

- **8/14 正式发布新一代旗舰基座模型 GLM-5.3**，号称「编程能力最强开源模型」，与 GLM-5.2 共用同一基座、**全靠后训练 Scaling 提能 50%**；同日上线编程工具 ZCode 与效率工具 AutoClaw。这是本周唯一也是最重要的产品事件。
- **8/13 大涨 9.02%（收 1317 港元）**，是市场在发布前一日对「GLM-5.3 复制前作大涨行情」的抢跑式投机买入（此前 GLM-5.1 发布当天 +11.5%、GLM-5.2 发布当天 +32.8%）。
- **8/14 高开低走收跌 3.57%（收 1270 港元）**：盘中一度冲高 +5.39%（最高 1435），尾盘跳水——大和证券直指 GLM-5.3 只是「常规迭代而非更大参数旗舰」、高盛仅维持「中性」，市场「预期落空」。
- **8/12 大和证券首予智谱「买入」评级、目标价 1500 港元**（窗口内），叠加南向资金当日净买入 4.17 亿港元，构成本周唯一的外部正面评级。
- 全周股价从 1252（8/10 收盘）到 1270（8/14 收盘），**几乎持平（约 +1.4%）但周内振幅巨大**，市值约 **5500–6100 亿港元区间（约 700–780 亿美元）**。

**一句话总结**：本周智谱用 GLM-5.3 证明了自己「不换基座、只做后训练」就能把智能上界再推高一截的顶级工程效率，但资本市场给出的回应是「预期落空、利好兑现」——市场要的不是「更好」，而是「更大的叙事跃迁」，这把智谱的估值分歧彻底暴露。

## 二、企业文化观察

本周窗口内无直接的文化事件，但智谱的文化画像已在 7 月唐杰内部信与大量深度报道中被立体勾勒：

1. **官方价值观 = Think Big / Deliver Solid / Scale Stable**（Z.ai 官网），配中文愿景「一群正直的、有激情的年轻人，聚在一起，做创新的、对社会有价值的事」。
2. **唐杰的六字方法论「本质、反直觉、专注」**：想得足够深才敢选得足够反，选得足够反就必须守得足够久。这是智谱「克制地聚焦、不追热点」风格的根源。
3. **「学院派 / 清华系 / 唐杰和他的门徒」组织底色**：AI 院负责模型训练的数百位研究员中 **70% 以上是清华计算机系本硕博**；组织被形容为「公司、学校、研究院的结合体」——层级扁平、更像实验室、关键方向常从一次技术讨论开始、年轻研究员提问题的空间大。
4. **师徒传承带来的低流失**：员工因对老师/学长的尊重与情感而稳定性高，形成区别于互联网大厂的技术人才库。
5. **稳健、不犯错的行事风格**：多位员工评价「每一步基本做对」，被业内形容为「清华理工男」式稳健。7 月内部信「别人敲钟，我们归零」把上市定性为「新起点而非终点」，契合其长期主义。

**综合判断**：当前智谱的企业文化是「**清华学院派的工程师文化 + 本质驱动、反直觉押注的长期主义 + 稳健克制不追风口**」，以唐杰的技术权威与师门关系为组织黏合剂。本周 GLM-5.3「不堆参数、只炼后训练」正是这种「反直觉」文化的产物。

## 三、核心产品更新要点

### 窗口内（本周最重要：8/14 GLM-5.3 发布）

**8/14：GLM-5.3 发布**（新一代旗舰基座模型，「编程能力最强开源模型」）

| 规格 | 数值 |
|---|---|
| 总参数 | 约 7430 亿（743B，MoE，与 GLM-5.2 相同） |
| 激活参数 | 约 400 亿（40B，激活比例 5.4%） |
| 上下文窗口 | 1M（100 万 token），最大输出 128K |
| 模态 | 仅文本（不支持多模态） |
| 支持能力 | 思考模式 / 流式 / Function Calling / 上下文缓存 / 结构化输出 / MCP |

- **最大卖点：基座零改动，全凭后训练 Scaling**。官方「Scaling post-training is all we did for GLM-5.3」；用约一个月扩大长程任务环境 + 强化学习训练（基于 IndexShare、SAO 与新一代 Slime 框架），把训练从「孤立编程题」扩展到「发现问题→分析→实施→验证→交付」完整流程（部分任务相当于资深工程师连续数天操作真实集群/存储/代码库的工作量）。
- **编程提能 50%**：Terminal-Bench 3.0 从 4.6 → 28.3；DeepSWE v1.1 从 46.2 → 66.9；Agents' Last Exam (CLI) 从 23.8 → 28.5。多项主流基准位列**开源第一**，整体逼近 Claude Fable 5 / Mythos 5 等闭源旗舰；Artificial Analysis Intelligence Index 60 分，与 Kimi K3 并列开源第一。
- **同日配套落地**：官方编程工具 **ZCode**、效率工具 **AutoClaw** 上线，GLM Coding Plan 全量用户可用（发布当天重置额度）。
- **权重延后开源**：发布时未同步开放权重，计划经安全审查后于 8/28 在 Hugging Face 开源——GLM 系列**首次有意延迟公开权重**，被市场读作「安全治理优先」的信号。发布时间曾流传「改名 GLM-5.5」「万亿参数级」传闻，均被官方否认为「谣言」。

### 窗口前紧邻背景（6/13–8/3）

- **6/13 GLM-5.2** 开源权重（753B MoE，长程 Agent 定位）。
- 8 月上旬的「开源第一梯队」格局：Kimi K3（AA 60 开源第一，月之暗面）、GLM-5.2（AA ~53）、DeepSeek V4-Flash（AA 52，0.14 美元超低价）、MiniMax-M3（AA 45）。

### 窗口后衔接事件（供下周摘要参考）

8/19 GLM-5.3 API 上线；8/21 国家超算互联网上线 GLM-5.3 API、官宣「权重下周五开源」；8/26 上线并开源 **GLM-5.3-Flash**（320B-A18B，GLM-5 系列首个原生多模态，认领海外匿名爆火模型「Ox-Alpha / 牛来」，全部流量由超 10 万张国产芯片承载）；8/28 GLM-5.3 权重正式开源。

## 四、护城河变化评估

**本周净判断：产品技术护城河加固，但「话语权 / 盈利质量」两端持续承压，攻守交织。**

### 加固方向

1. **后训练 Scaling 的工程效率壁垒（本周最确定的增强项）**：GLM-5.3 不换基座、纯靠后训练把编程能力提升 50% 并摸到开源第一，证明智谱在「智能上界」上的工程能力与算力利用效率——这是比「堆参数」更稀缺、也更难复制的护城河。
2. **MaaS 生态飞轮量价齐升**：截至 8 月末 MaaS 平台用户超 740 万，Token 调用量较年初增长超 40 倍，API 平均售价反而提高约 101%，API 业务毛利率从去年同期 -0.4% **转正至 24.6%**——「提价 + 放量」同时发生，说明 GLM 的智能上界正在转化为真实议价权。
3. **国产算力自主可控（窗口后 8/26 确认）**：GLM-5.3-Flash 大规模免费测试的全部流量由超 10 万张国产芯片承载（供应链涉华为、摩尔线程、海光等），在「东数西算 / 算力自主」+ 出口管制背景下，这是不同于海外与部分同行的地缘性护城河。
4. **人才 / 师门壁垒**：清华系 + 70% 以上 AI 院研究员出自清华 CS，低流失形成的技术人才库难以短期复制。

### 受侵蚀方向

1. **开源「话语权」被稀释**：Kimi K3（2.8T，AA 60）、DeepSeek V4-Flash（超低价）、Qwen3.8-Max（2.4T）全部开源并占据「开源第一 / 最高性价比」心智；GLM-5.3 只是「并列第一」，智谱不再独享「开源 SOTA」标签。
2. **「只会后训练」的质疑发酵**：市场担心其预训练/基座迭代能力被后训练短期红利透支（后续每经报道智谱需回应「下一代基座已推进，GLM-6.0 瞄准自进化」）。8/14 股价「利好兑现即跌」本质是市场对「护城河是否可持续」的投票。
3. **价格战 + 毛利率腰斩**：整体毛利率从去年同期 50% 降至 26.4%，「卖 Token」的低毛利 + 国产算力爬坡成本高企；DeepSeek 以 0.14 美元超低价、智谱以「十分之一价格」互相杀价，B 端定价权承压。
4. **客户转换成本低**：杰富瑞（窗口后）指出客户集中、切换成本低，云业务估值倍数需从 50 倍 2026E ARR 下调至 30 倍以对齐海外同业——这是对「生态黏性」护城河的直接质疑。

**结论**：智谱护城河的本质是「**智能上界的工程效率 + MaaS 生态量价齐升 + 国产算力自主 + 清华人才**」，而非单点绝对第一或生态锁定。本周 GLM-5.3 加固了「工程效率」与「智能上界」两条最核心的护城河，但开源话语权与盈利质量（毛利率、客户黏性）正在被行业价格战与「后训练质疑」侵蚀。**API 毛利率能否在价格战下持续抬升，是护城河的最大观察指标。**

## 六、商业模式变化

**本周窗口内商业模式无宣告式变化，但一条结构性反转正在被财报确认（窗口后 8/31 半年报交出答卷）：**

1. **收入结构历史性反转（从「卖项目」到「卖 Token」）**：开放平台及 API 业务收入从 2025 年占比 15.2% 飙升至 2026 H1 的 **86.5%**（8.25 亿元，同比 +2736%）；本地化私有化部署业务从 2025 年第一大收入（占比 73.7%）降至 6704 万元（-54.6%）。智谱从一个「政企交付 / 定制化项目公司」，被彻底重新定价为「**MaaS（模型即服务）基础设施公司**」。
2. **「智能上界 × Token 消耗规模」的商业公式落地**：张鹏提出的「AGI 商业价值 = 智能上界 × Token 消耗规模」正被数据验证——模型越强 → API 单位定价越高（+101%）→ 调用越多（Token 量 +40 倍）→ 收入指数增长。GLM-5.3 本周发布即是为了继续抬「智能上界」这一乘数。
3. **渠道零售化 / 订阅化试水**：GLM Coding Plan（Lite/Pro/Max）本周全量上线，是「Token 订阅制」从开发者走向更广付费用户的节点；窗口后 9/2 更以天猫旗舰店零售 Token 套餐（C 端化），把 API 能力标品化。
4. **隐忧仍在盈利端**：H1 收入 9.54 亿元（+399.7%）、毛利 2.52 亿元（+163.7%），但整体毛利率从 50% 腰斩至 **26.4%**（销售成本同比 +635%）、研发开支 21.31 亿元、净亏损 20.72 亿元——「增收不增利」未解，卖 Token 的低毛利与算力高成本是结构性约束。

**价值投资者视角**：商业模式的「质量」在快速改善（高毛利 API 占比上升、量价齐升、API 毛利率转正 24.6%），但「验证」远未完成——**盈利模型（毛利率、C 端付费闭环）与 ARR 的可持续性（杰富瑞质疑）是未来 2–4 个季度的核心观察点**。本周 GLM-5.3 是「抬智能上界」商业公式的又一次执行，而非模式本身的改变。

## 七、行业竞争格局与公司优劣势

### 截至 2026 年 8 月中旬的行业格局

- **「中国大模型八周五连发」**：6/13 GLM-5.2、7/17 Kimi K3（2.8T 开源登顶）、7/31 DeepSeek V4-Flash（超低价 MIT 开源）、7/31 字节 Seedance 2.5（视频）、8/3 阿里 Qwen3.8-Max（2.4T 首次开源 Max 级）——中美顶尖模型性能差距大幅收窄，硅谷企业因成本「换底座」。
- **开源第一梯队（Artificial Analysis Intelligence Index，截至 8 月中旬）**：Kimi K3 与 GLM-5.3 并列 AA 60（开源第一，仅距闭源 Claude Opus 8 系列 3 分）；DeepSeek V4-Flash 52（0.14 美元超低价）；MiniMax-M3 45（高编码性价比）。四款主流国产 LLM 全部开放权重。
- **行业竞争维度转换**：从「比模型」进入「比商业化（MaaS/ARR）、比算力自主、比资本」。上市平台（智谱、MiniMax）与冲刺 IPO（月之暗面、阶跃星辰）分化定局，「六小虎」格局清晰化。
- **价格战**：DeepSeek 提价 9 天后，智谱以「十分之一价格」杀入；同时 DeepSeek 的 0.14 美元低价仍是行业性价比基准。

### 智谱竞争优势

1. **智能上界的工程效率第一**：GLM-5.3 证明「同基座纯后训练提能 50%」的极致效率，在「工程优化 + 性价比」路线（而非堆参数）上领跑。
2. **MaaS 商业化最成熟**：740 万+ 用户、Token 量 +40 倍、API 均价 +101%、毛利率转正——量价齐升的飞轮在国产第一梯队中最扎实。
3. **国产算力自主**：GLM-5.3-Flash 全流量由 10 万张国产芯片承载，自主可控 + 地缘护城河。
4. **资本与人才**：上市平台 + 7 月 314 亿港元配售（年内港股单笔配售新高）的融资能力；清华师门人才库。

### 智谱竞争劣势

1. **单点性能非绝对第一**：开源榜单与 Kimi K3 并列第一而非独享；视频（Seedance/Kling）、多模态（GLM-5.3 本身仅文本，需等 Flash 补齐）等维度未必领先。
2. **亏损与盈利质量**：H1 净亏损 20.72 亿元、毛利率 26.4%（腰斩）、研发开支远超营收——盈利拐点遥远。
3. **估值透支 + 高博弈**：PS 超 200 倍、空头与解禁压力、股价从峰值回撤 40%+，估值弹性脆弱。
4. **C 端付费闭环未跑通**：收入仍集中在政企/开发者 B 端，普通用户订阅的可迁移性与黏性存疑（客户转换成本低）。
5. **「后训练依赖」的叙事风险**：与 DeepSeek（极致性价比）、MiniMax（全模态 + 开源权重）、月之暗面（长文本 + 阿 Math 生态）相比，市场对智谱「下一步基座 / 自进化」兑现节奏存疑。

## 八、综合结论与观察点

**本周画像**：一家「全球大模型第一股」，在 8/14 用 GLM-5.3 再次证明了自己「不换基座、只炼后训练」就能抬升智能上界的顶级工程效率，但资本市场的回应是「预期抢跑（8/13 +9%）→ 利好兑现即跌（8/14 -3.57%）」——说明仅靠「更好的模型」已不足以推动其高企的估值继续扩张，市场要的是更大的叙事（国产算力、自进化基座、RPO 兑现）。

**对价值投资者的关键观察点（后续跟踪）**：
1. **ARR 的含金量与可持续性**：8 月末 16 亿美元 ARR（「最近一周×52」口径 20 亿美元）能否转化为确认收入，客户是否「集中且低粘性」（杰富瑞质疑）；
2. **API 毛利率能否持续抬升**：价格战（DeepSeek 0.14 美元）与国产 GPU 集群上线双重挤压下，转正的 24.6% 毛利率是护城河试金石；
3. **GLM-6.0 基座 / 「自进化」的兑现节奏**：对「只会后训练」质疑的回应，决定估值叙事的下一跳；
4. **国产算力自主的规模化落地**：10 万张国产卡叙事的真实利用率与推理性价比；
5. **解禁与空头压力**：7/8 首批解禁后的下行通道 + 7 月 1588 港元配售机构浮亏，与 GLM-5.3 权重开源（8/28）能否带来生态反哺的博弈。
