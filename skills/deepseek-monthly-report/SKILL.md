# 研究公司

公司名=DeepSeek

# overview

当前skill用于生成价值投资月度报告。

当前skill 所有描述中，yyyy-MM 是当前年和上个月的月份

生成的 markdown 文档顶部必须生成目录，方便跳转查看。


# 月度报告生成步骤

- 首先读取 D:\walker\invest-agent\report\{yyyy-MM}\{公司名} 下面的 这个公司所有每周摘要，这些每周摘要 markdown 文件是由 /deepseek-weekly-digest skill 生成的。
- 然后将所有的摘要markdown 进行合并去掉重复的内容，不要简化内容 ，得到一个摘要合并结果。
- 然后将摘要合并结果 作为输入，带入下面定义的 walker价值投资分析框架 去分析
- 最后得到一个详尽的月度分析报告：
  生成的月度报告为 markdown文件，存放于 D:\walker\invest-agent\report\{yyyy-MM}\{公司名} 目录, 文件名称格式为 公司名-月度报告-yyyy-MM 。
 

# walker价值投资分析框架
- 公司管理层分析
从摘要合并结果中 直接提取管理层的近期说话要点，进行分析总结出管理层的观念和思维方式。 
然后除了上面近期的总结，请分析总结出历史上 管理层 核心人物的观念和思维方式，以及他们的行事原则。
然后并分析管理层是否出现过 重大人品问题以及是否有失信等不良情况。
最后总结出 该公司管理层的 观念和思维方式以及行事原则，并结合科技行业历史上类似管理层（类似观念，思维方式，行事原则的管理层）的最后结局是什么 来评判当前管理层的好坏。

- 公司文化分析
从摘要合并结果中直接提取最近 公司文化要点。
然后除了上面近期的公司文化要点，请分析总结出历史上该公司的文化特点是什么，并结合当前其他知名科技公司的文化特点 来评判当前公司文化的好坏。

- 护城河分析
从摘要合并结果中直接提取最近 公司护城河分析结论，并结合科技行业常见 护城河模式 来评判当前公司的护城河好坏。

- 商业模式分析
从摘要合并结果中直接提取最近 公司商业模式分析结论，并结合科技行业常见 商业模式 来评判当前公司的商业模式好坏。
- 竞争格局分析
从摘要合并结果中直接提取最近 竞争格局分析结论，并结合科技行业知名竞争案例，来评判当前公司竞争优势是否能持续，以及当前公司的竞争劣势会不会持续拖累公司影响公司发展。

- 产品更新要点
从摘要合并结果中直接提取最近 核心产品的更新要点

- 公司估值分析
从摘要合并结果中直接提取最近 公司估值分析结论。 如果估值偏高，请结合科技行业发展规律，预测什么时间点估值会变得合理，以及什么时候此公司估值会比较低而产生投资机会。

- 其他要点
除了上面列出的价值投资分析要点，请结合主流价值投资的分析框架，查缺补漏，进行其他价值投资要点分析。
