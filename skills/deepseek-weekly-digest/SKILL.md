# overview

当前skill用于生成价值投资每周摘要。
生成的摘要为 markdown文件，存放于 D:\walker\invest-agent\report\{yyyy-MM}\{公司名} 目录, 其中 yyyy-MM 为摘要区间开始日期所在的年和月份。
文件名称格式为 公司名-每周摘要-{摘要区间开始日期}至{摘要区间结束日期} ，比如 DeepSeek-每周摘要-2026-08-27至2026-09-02.md。

生成的 markdown 文档顶部必须生成目录，方便跳转查看。

# 调用参数（摘要区间）

调用本 skill 时可以传入本次摘要的时间段参数，格式为：

from yyyy-MM-dd to yyyy-MM-dd

例如：`from 2026-08-01 to 2026-08-07`（也兼容 `2026-08-01至2026-08-07` 的写法）。

- 如果传入了该参数，则本次摘要的"摘要区间"为该时间段（含开始日期和结束日期两天）。
- 如果没有传入该参数，则摘要区间默认为最近 7 天（以当前日期为结束日期，往前推 7 天）。

下文所有"摘要区间"均指按上述规则确定的时间段。

# 摘要收集和研究列表

下面的信息收集和研究请深入的收集分析 和 深入的研究。

- 收集摘要区间内公司实际控制人的发言和相关文章，总结出这段时间他对外说话的要点。（实际控制人可以是一到多个人的发言总结）。
- 收集摘要区间内公司文化相关的信息， 总结出这家公司当前的企业文化是什么。
- 收集摘要区间内公司护城河的变化，是护城河遭到了其他公司破坏，还是在加固。
- 研究摘要区间内公司的商业模式是否发生变化。
- 研究摘要区间内公司所在行业的竞争格局是怎样的， 公司的竞争优势和劣势是什么。
- 收集摘要区间内公司核心产品的更新信息，总结出更新要点。
- 研究摘要区间内公司的股票市值，是估值太高，还是一般，还是低。
